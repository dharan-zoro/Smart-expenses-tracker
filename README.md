# VANTA — Smart Expense Tracker

A responsive dark-glassmorphism expense tracker built with plain HTML, CSS and JavaScript.

## Run
1. Extract `smart-expense-tracker.zip`.
2. Open `index.html` in Chrome, Edge or Firefox.
3. No installation, build step, server or backend is required.

## Features
- Dashboard with balance, income, expense and monthly budget summaries
- Add income and expense transactions
- Category selection, dates and optional notes
- Search and filter transactions
- Delete transactions
- Monthly budget tracking and progress indicator
- Cash-flow chart for the last 6 or 12 months
- Category spending breakdown and insights
- Export transactions to CSV
- Browser LocalStorage persistence
- Responsive layout for mobile and desktop

## Data and privacy
All records are stored in this browser using LocalStorage. This is a frontend-only demo; it does not sync between devices or provide cloud backups. Clearing browser site data may remove saved records. Export CSV regularly if you need a backup.

## Files
- `index.html` — page structure
- `style.css` — responsive dark glassmorphism design
- `app.js` — app logic and LocalStorage
